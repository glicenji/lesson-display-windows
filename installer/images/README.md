# Installer artwork

Everything in this folder is generated by `generate_assets.py` from the four
source photos in `source-photos/` — you never need to hand-edit a `.bmp` or
`.ico` here directly.

## To use different photos

1. Replace the files in `source-photos/` (keep the exact names):
   - `icon.png` — becomes the app's icon (Start Menu, taskbar, .exe, the
     installer itself). Square works best; a transparent background is
     fine and expected (it gets blended into a blue background for the
     wizard banner images, but stays transparent in the actual .ico).
   - `slide-1.png`, `slide-2.png`, `slide-3.png` — the three photos shown
     one after another (7 seconds each, crossfading between them) on the
     installer's "About ClassSync" page. Any common image format
     works, not just PNG — just edit the `SLIDE_SRCS` list at the top of
     the script if you'd rather use a different extension.
2. From the repo root (or anywhere), run:
   ```
   python3 installer/images/generate_assets.py
   ```
   (needs Pillow: `pip install pillow` if you don't have it — this is the
   only place in the whole project that needs Python; nothing at build or
   run time depends on it.)
3. Commit the regenerated files and push — the next installer build picks
   them up automatically.

## What gets generated, and where it's used

| File | Size | Used by |
|---|---|---|
| `../../assets/icon.ico` | multi-resolution | Both apps' `<ApplicationIcon>`, and `SetupIconFile` in `LessonDisplaySetup.iss` — so the installer, the Start Menu/Desktop shortcuts, and both .exe files all show the same icon. |
| `wizard-image.bmp` | 164×314 | The big illustration on the installer's Welcome/Finished pages (`WizardImageFile`). Built by compositing the icon art onto a blue gradient with "ClassSync" underneath. |
| `wizard-small.bmp` | 55×58 | The small logo in the corner of every other wizard page (`WizardSmallImageFile`). Same icon art, no text. |
| `slideshow/*.bmp` | 380×214, 36 frames | The "About ClassSync" page's slideshow (see the `[Code]` section in `LessonDisplaySetup.iss`). Each pair of photos gets 12 crossfade frames rendered in Python; Setup just displays them on a timer — it never blends anything itself. |

## Why a whole custom wizard page, not just `WizardImageFile`

Inno Setup's `WizardImageFile` only supports a single static image (or a
few, picked by DPI — not an animated sequence). A real slideshow with a
crossfade needed a custom page with its own timer-driven bitmap, which is
what the `[Code]` section does. It's the one part of this installer that
genuinely couldn't be tested without a Windows machine and Inno Setup
installed — see the "What's been tested vs. not" section of the top-level
README for the honest status.
